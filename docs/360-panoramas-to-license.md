# 360° panoramas to license (360Cities)

These 360Cities panoramas were picked for the catalogue. They belong to their photographers: a commercial site may
show them only with a paid **Hosted Embed** licence (360Cities → cart → Category "Hosted Embed", Subcategory
"Any Usage", choose the duration). After payment 360Cities emails the embed code
(`https://www.360cities.net/paid_embed_iframe/{licence}/{panorama}`).

To publish: CMS → Locations → the location → Media → "360° по коду встраивания" → paste the code, add labels and
the credit (author / licence term) → Save. The site shows the player in the 360° block, loaded only after a click.
